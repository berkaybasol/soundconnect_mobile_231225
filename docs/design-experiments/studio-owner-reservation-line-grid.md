# Studio Owner Reservation Line Grid Experiment

Status: Paused experiment. Preserved so the visual direction can be restored
without reconstructing its behavior from memory.

## Concept

- Four-column hourly availability grid.
- Reservation duration represented by a glowing status-colored line.
- Confirmed reservations used vivid green; pending reservations used amber.
- Reserved time-cell borders matched the line color.
- A tappable user avatar was positioned on the reservation line.
- The avatar opened owner actions for approval, details, profile preview and
  cancellation.

## Reason paused

Long reservations crossing a four-column row boundary were visually difficult
to follow. Several routing approaches made unrelated time cells appear to be
part of the reservation. The vertical daily timeline is active while this
direction remains paused.
